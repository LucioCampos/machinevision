Testes de classficação de animais (cachorro,, gato e panda) utilizando diversas técnicas de machine learning: As 3 primeiras técnicas de classificação (KNN, SVM e MLP)
utilizaram o descritor de características HOG. Já os classificadores baseados em Redes Convolucionais, utilizam a imagem inteira como entrada,
dispensando o uso de descritores de características. Observe que o melhor resultado é obtido por meio de uma CNN já treinada, que facilita
bastante o processo.
